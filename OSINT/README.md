# OSINT 滚动记忆文档

> 本目录为 OSINT 主题的滚动记忆存储目录，按执行分类维护。
> 最后更新：见各子目录内文档头部时间戳。

## 目录结构

| 目录 | 用途 | 说明 |
|------|------|------|
| `01-target/` | 目标域名范围 | 记录当前授权的目标域名、资产范围、排除项 |
| `02-authorization/` | 已授权书 | 存放/登记授权书文件，记录授权范围与有效期 |
| `03-poc/` | 手动 POC | 手动验证的 POC 脚本、步骤、结果 |
| `04-reproduction/` | 复现文档 | 漏洞/发现的可复现操作文档与证据 |
| `05-releases/` | 最新功能发布通知 | 工具/平台功能更新与发布通知 |
| `06-tools/` | 工具配置与 MCP 接入 | 记录工具安装、key 接入、MCP server 演进与当前清单 |

## 滚动规则

1. 每个子目录维护一个 `ROLLING.md` 作为滚动记忆正文，新记录追加到顶部（最新在上）。
2. 超过 100 条时，将最旧条目压缩为一条摘要（保留要点，删除细节）。
3. 关键结论同步回本 `README.md` 的"当前状态"小节。
